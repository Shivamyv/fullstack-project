# WanderLust 🌍

A full-stack travel accommodation platform inspired by Airbnb where users can explore, create, review, and manage property listings from around the world.

---

## 🚀 Live Demo

🔗 Live Website:https://fullstack-projects-4f4j.onrender.com/listings

---

# ✨ Features

* 🔐 User Authentication & Authorization
* 🏠 Create, Edit & Delete Listings
* 📸 Image Uploads with Cloudinary
* ⭐ Review & Rating System
* 🗺️ Interactive Map Integration
* 📱 Responsive UI Design
* 🔔 Flash Messages & Error Handling

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Shivamyv/fullstack-project.git
```

## 2️⃣ Move into Project Directory

```bash
cd fullstack-project
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Create `.env` File

Add the following variables:

```env
ATLASDB_URL=your_mongodb_connection_string
SECRET=your_secret_key
CLOUD_NAME=your_cloudinary_name
CLOUD_API_KEY=your_cloudinary_api_key
CLOUD_API_SECRET=your_cloudinary_api_secret
MAP_TOKEN=your_mapbox_token
```

## 5️⃣ Run the Project

```bash
node app.js
```

or

```bash
nodemon app.js
```
